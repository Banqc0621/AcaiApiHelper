## 请求状态机

```text
idle -> running -> succeeded | failed | cancelled
```

- `running` 时发送按钮进入 loading，停止按钮可用。
- `cancelled` 必须终止或忽略后台结果，恢复按钮、文案、颜色和光标。
- 异常必须转换为可展示错误结果，不能把按钮永久留在禁用态。

## 前置脚本安全边界

- 不在 IDE 进程内执行 JavaScript、Shell 或任意代码。
- 仅支持 `set name=value`、`param name=value`、`header name=value` 三种命令及注释。
- 变量覆盖在本次请求的环境副本中生效，不污染项目环境；脚本错误会在请求发出前阻断。
- 单请求停止通过中断活动任务实现，取消结果标记为 `CANCELLED`，迟到回调由请求序号丢弃。

## 节点 A 数据合并规则

- 收藏交换文件只包含文件夹、接口键、文件夹级参数和状态，不包含 AI 凭据、接口历史或完整配置。
- 本地已有数据优先；同名文件夹和同 ID 同名文件夹合并。
- 导入文件夹与本地同 ID 但名称不同时生成新 ID，参数和状态随映射迁移。
- 无效格式、未知版本、空/重复文件夹 ID 在写入前拒绝；导入完成后从文件夹成员重建收藏索引。
