# Acai API Helper - IDEA插件 v1.0.3

企业级API调试与自动化测试插件，在IDEA内完成接口调试、AI参数生成、自动化测试。

## ✨ v1.0.3 优化更新（2026-07-09）

### 🤖 AI 配置界面优化

1. **提示词可折叠（互斥）** - 系统/用户提示词默认折叠，点击其一展开时自动折叠另一个，同时只能打开一个，高度自适应
2. **底部按钮同一排** - 「恢复默认提示词」「确定」「取消」放至底部同一行，减小上下高度
3. **横向伸缩生效** - 对话框左右拉伸时输入框撑满、API Key 小眼睛跟随右移（`ScrollableGridBagPanel`）
4. **API 路径允许留空** - 留空时请求直接打到 Base URL 根路径，修复主 HTTP 入口硬编码 `/chat/completions` 的问题

### 🔍 API 接口扫描增强（修复接口列表显示不全）

1. **路径占位符不再丢弃** - `${key:default}` 取默认值、`${key}` 取变量名，仅 SpEL `#{...}` 丢弃
2. **组合注解控制器可发现** - 补充按类级 `@RequestMapping` 搜索
3. **方法级 `@*Mapping` 反向定位** - 方法标了 `@GetMapping` 等即纳入其所属类，兜底 Kotlin/轻量控制器
4. **多路径注解完整展开** - `@GetMapping({"/list","/query"})` 展开为多个接口
5. **方法重载不再误去重** - 去重键加入方法名+参数签名
6. **Kotlin/无名类控制器不再整类丢失** - qfn 为 null 时用「类名+源文件路径」兜底去重
7. **自定义 ErrorController 控制器不再被误杀** - 移除「实现 ErrorController 即整类丢弃」判定
8. **扫描总结日志增强** - 输出「候选→去重→产出」全链路计数
9. **路径常量引用解析** - `@GetMapping(ApiConstants.PATH)` 等 `static final String` 常量引用解析出实际路径值
10. **多类级基路径展开** - `@RequestMapping({"/api/v1","/api/v2"})` 多前缀下的方法路径完整识别（笛卡尔积）
11. **逐控制器诊断增强** - 输出 `qfn + 映射方法数 + 产出数 + 被过滤方法名`，0 接口时区分「无映射」与「全被过滤」

### 📝 AI 参数体格式化修复

- 修复请求体 `\"`/`\n` 双重转义乱码，新增 `mapToNestedJson` 还原嵌套结构，输出规整可读 JSON

### 🌐 环境管理回显修复

1. 对话框激活环境后主面板 Base URL / 请求头立即回显
2. 下拉框切换环境时注入该环境的全局请求头
3. 修复下拉框重建期间的误切换环境问题

## 🚀 使用说明

### 快速开始
1. 右侧工具栏点击「AcaiApiHelper」打开面板
2. 点击「扫描API」自动识别项目中的Spring MVC接口
3. 左侧树选择接口，右侧填写参数后点击「发送」

### 环境管理
- 工具栏「管理」按钮打开环境配置对话框
- 支持配置多套环境（开发/测试/生产）的BaseURL和变量
- 在请求中使用 `{{variableName}}` 引用环境变量，例如 `Authorization: Bearer {{token}}`

### 断言配置
- 切换到「断言」Tab添加响应断言
- 支持状态码、响应时间、响应体内容、JSON字段值、响应头等多种断言类型
- 点击「🤖 AI生成断言」可让AI自动推断合理的断言规则

### 导出功能
- **导出cURL**：将当前请求复制为cURL命令，方便在终端/Postman中使用
- **导出文档**：导出所有接口为Markdown格式的API文档
- **导出报告**：测试完成后导出HTML测试报告

## 🔧 编译安装

```bash
./gradlew buildPlugin
```

编译产物位于 `build/distributions/` 目录，在IDEA中通过「设置 -> 插件 -> 从磁盘安装插件」选择zip包即可。

## 📁 数据存储位置

- 插件配置：`.idea/acai-api-helper.xml`（项目级）
- 测试报告：`.acai/reports/`
- 导出文档：`.acai/api-doc.md`

## 🎯 核心特性

### AI参数生成
对接火山引擎方舟(ARK)大模型，根据接口名、参数名、参数类型智能生成符合业务语义的测试数据。
支持正常值/边界值/异常值/全量覆盖四种场景。

### Git预提交检查
提交代码时自动测试受影响的Controller接口，测试失败可阻断提交，防止问题代码进入仓库。
- 每个接口按其预期状态码判定，不再一刀切使用200
- 失败时显示具体失败接口、状态码和错误信息

### 编辑器集成
- Controller方法行号旁显示API图标，点击快速打开调试面板
- 右键菜单支持「调试此接口」「收藏」「复制为cURL」等操作
- 双击API节点跳转到对应源码位置
