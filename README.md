# RestAutoLab - IDEA插件 v2.0.0

企业级API调试与自动化测试插件，在IDEA内完成接口调试、AI参数生成、自动化测试。

## ✨ v2.0.0 UI 体验大升级版（2026-07-13）

### 🎨 响应区 JSON 语法高亮与交互增强

1. **JSON 语义高亮** - 新增 `JsonSyntaxPane`，对键名 / 字符串 / 数字 / 布尔 / null / 标点按语义着色，明暗主题自适应
2. **字体缩放** - 支持 `Ctrl+滚轮` / `Ctrl++/-` / `Ctrl+0` 缩放（10–24px），右键菜单提供「放大 / 缩小 / 重置」
3. **右键菜单** - 复制选中 / 复制全部 / 全选 / 字体缩放，一键操作无需记忆快捷键
4. **UI 语义色板** - `UiStyle` 新增 JSON 语义色板（KEY / STRING / NUMBER / BOOLEAN / NULL / PUNCTUATION）与 `ghostButton` 透明按钮样式

### 📝 参数智能编辑器

1. **独立编辑器组件** - 抽取为独立 `SmartValueEditor`，支持文件选择、多行 JSON 编辑器、枚举智能提示（status/gender/sort/pay 等场景化建议）
2. **文件上传参数** - File / Multipart 类型或 FILE 位置参数显示「选择文件」按钮，选中后回写路径并同步附件标签
3. **多行 JSON 编辑器** - BODY 位置或疑似 JSON 值显示「展开」按钮，弹窗支持一键格式化 / 编辑 / 确定

### ⌨️ 请求体编辑与视图优化

1. **撤销 / 重做** - 请求体编辑器支持 `Ctrl+Z` / `Ctrl+Y` 撤销重做
2. **折叠展开** - 失焦自动折叠为 6 行（给响应区让出空间），获焦自动展开为 18 行；长 JSON 不自动换行，水平滚动查看
3. **响应视图切换增强** - 切换到响应 Tab 时若处于树形视图自动切回文本视图，保证下次请求展示一致
4. **清空响应联动** - 清空按钮同时清空响应文本区、高亮视图，并重置视图状态

## ✨ v1.0.5 收藏文件夹与异常加固版（2026-07-10）

### ⭐ 收藏文件夹管理

1. **自定义文件夹分组** - 新增「收藏」分类视图，支持自定义文件夹分组收藏接口
2. **文件夹内操作** - 文件夹内接口支持重命名 / 删除 / 拖拽移动，同文件夹自动去重
3. **参数独立归档** - 同一接口在不同文件夹可保存各自独立的测试参数，互不干扰

### 🔁 智能分类与批量操作

1. **「最新」分类过滤** - 基于 Git 变更检测，展示最近 30 天有提交涉及的接口；后台线程预计算，避免阻塞 UI
2. **批量 AI 生成参数** - 文件夹右键一键为其中所有接口生成测试参数并持久化，进度实时反馈
3. **批量接口测试** - 文件夹右键批量执行接口测试，结果按通过/失败标红高亮，支持「取消警示」手动清除

### 📤 导出与稳定性增强

1. **多选导出增强** - Markdown / Postman JSON 导出严格按用户多选节点生成，不再静默展开 Controller；导出前二次确认按 Controller 分组预览
2. **编译错误修复** - 修复「调试此接口」右键动作调用 `Consumer.accept(api, null)` 导致编译失败的问题
3. **异常处理加固** - 「调试此接口」回调与「跳转到源码」操作包裹 try-catch，非法行号退化为不指定行避免 `IllegalArgumentException`，错误以对话框形式提示并记录日志

## ✨ v1.0.4 数据管理重构版（2026-07-09）

### 📂 数据管理统一入口

合并导出/导入按钮为「数据管理」弹窗，分为「配置」与「接口数据」两类，职责清晰。

### ⚙️ 配置导入导出

1. **导出配置** - 一次导出 AI 设置 + 环境配置 + 测试 Profile；导出前实时摘要核对（服务器/模型/Key脱敏/提示词），确保导出的是当前实时配置而非默认占位值
2. **导入配置** - AI 设置覆盖当前；环境与 Profile 按"本地已有同名保留本地，否则新增"合并
3. **AI 配置导出修复** - 修复 `arkModelCode` 等字段导出为默认值而非实时值的问题；移除冗余轻量模型(code)字段，统一通过 getter 读取

### 🔌 接口数据导入导出

1. **导出接口数据** - 导出全量接口定义 + 已测接口测试数据 + 统计/收藏
2. **导入接口数据** - 按接口粒度合并：本地已测过的接口保留本地不覆盖，未测过的接口导入其测试记录；接口定义按 method|url 去重新增

### 🌐 环境切换✓修复

修复环境下拉框对号始终指向开发环境的问题。原 `Environment.toString()` 依据冗余的 `active` 字段显示 ✓，而切换环境时该字段未同步刷新。改用下拉框渲染器实时跟随选中项，✓ 始终与实际激活环境一致。

## 🚀 使用说明

### 快速开始
1. 右侧工具栏点击「RestAutoLab」打开面板
2. 点击「扫描API」自动识别项目中的Spring MVC接口
3. 左侧树选择接口，右侧填写参数后点击「发送」

### 环境管理
- 工具栏「管理」按钮打开环境配置对话框
- 支持配置多套环境（开发/测试/生产）的BaseURL和变量
- 在请求中使用 `{{variableName}}` 引用环境变量，例如 `Authorization: Bearer {{token}}`

### 收藏文件夹
- 点击接口星标 ⭐ 收藏到「收藏」分类
- 支持自定义文件夹分组，文件夹内接口可重命名/删除/拖拽移动
- 文件夹右键支持「批量 AI 生成参数」「批量接口测试」
- 「最新」分类基于 Git 变更展示最近 30 天有提交涉及的接口

### 断言配置
- 切换到「断言」Tab添加响应断言
- 支持状态码、响应时间、响应体内容、JSON字段值、响应头等多种断言类型
- 点击「🤖 AI生成断言」可让AI自动推断合理的断言规则

### 数据管理
- 工具栏「数据管理」按钮打开统一弹窗，分为「配置」与「接口数据」两类
- **配置导入导出**：一次导出/导入 AI 设置 + 环境配置 + 测试 Profile
- **接口数据导入导出**：导出全量接口定义 + 测试数据；按接口粒度合并导入

### 导出功能
- **导出cURL**：将当前请求复制为cURL命令，方便在终端/Postman中使用
- **导出文档**：导出所有接口为Markdown格式的API文档
- **导出Postman**：导出为 Postman Collection v2.1 JSON，可被 Postman / Apifox 直接导入
- **导出报告**：测试完成后导出HTML测试报告

## 🔧 编译安装

```bash
./gradlew buildPlugin
```

编译产物位于 `build/distributions/` 目录，在IDEA中通过「设置 -> 插件 -> 从磁盘安装插件」选择zip包即可。

### 兼容版本

插件基于 `org.jetbrains.intellij.platform` 构建（Java 17 编译），`idea-version` 声明为 `since-build="223" / until-build="261.*"`，覆盖 4 年共 11 个大版本：

- ✅ IntelliJ IDEA 2022.3 / 2022.3.x（最低支持）
- ✅ IntelliJ IDEA 2023.1 / 2023.2 / 2023.3 及子版本
- ✅ IntelliJ IDEA 2024.1 / 2024.2 / 2024.3 及子版本
- ✅ IntelliJ IDEA 2025.1 / 2025.2 / 2025.3 及子版本
- ✅ IntelliJ IDEA 2026.1 / 2026.1.x（最高支持）
- ❌ 2022.2 及以前：物理上不支持
- ❌ 2026.2+：暂不支持，需等待下一版调整 `untilBuild`

可通过菜单 `Help → About` 查看当前 IDE 版本号（build 号 223 ~ 261）。

## 🎯 核心特性

### AI参数生成
对接火山引擎方舟(ARK)大模型，根据接口名、参数名、参数类型智能生成符合业务语义的测试数据。
支持正常值/边界值/异常值/全量覆盖四种场景。

### Git预提交检查
提交代码时自动测试受影响的Controller接口，测试失败可阻断提交，防止问题代码进入仓库。
- 每个接口按其预期状态码判定，不再一刀切使用200
- 失败时显示具体失败接口、状态码和错误信息

### 编辑器集成
- Controller方法行号旁显示API图标，点击快速打开调试面板
- 右键菜单支持「调试此接口」「收藏」「复制为cURL」等操作
- 双击API节点跳转到对应源码位置

### 响应区 JSON 高亮（v2.0.0）
- 键名 / 字符串 / 数字 / 布尔 / null / 标点按语义着色，明暗主题自适应
- `Ctrl+滚轮` / `Ctrl++/-` / `Ctrl+0` 缩放字体（10–24px）
- 右键菜单：复制选中 / 复制全部 / 全选 / 字体缩放
