# Acai API Helper - IDEA插件 v3.0.0

企业级API调试与自动化测试插件，在IDEA内完成接口调试、AI参数生成、自动化测试。

## ✨ v3.0.0 功能完善版

### P0 v2遗留问题修复 (6项，100%完成)

1. **✅ 按接口自定义预期状态码** - 不再一刀切使用2xx判断，每个接口可单独配置允许的HTTP状态码
2. **✅ 环境变量全链路生效** - `{{variableName}}`语法在URL、Header、请求体中均会被正确替换
3. **✅ 测试用例持久化** - 测试Profile保存到项目配置，重启IDEA不丢失
4. **✅ AI配置与全局设置同步** - AI配置弹窗保存后，所有字段（URL/Key/Model）立即同步生效
5. **✅ Cookie自动管理** - 自动保存和发送Cookie，支持手动清空，跨请求保持会话
6. **✅ 测试报告HTML导出** - 支持导出带通过率统计和详情表格的可视化HTML报告

### P1 核心功能增强 (6项)

1. **✅ 请求历史记录** - 保留最近100条请求，支持重发、对比，持久化到本地
2. **✅ 接口收藏/标签** - ⭐收藏常用接口，独立分类标签展示
3. **✅ form-urlencoded支持** - 请求体支持JSON/表单格式切换
4. **✅ 可视化断言编辑器** - 9种断言类型（状态码/响应时间/Body包含/JSON字段/Header等）
5. **✅ 环境变量管理面板** - 可视化新建/编辑/删除/切换环境，支持变量预览
6. **✅ cURL导入/导出** - 一键复制为cURL命令，也可从cURL导入请求配置

### P2 创意产品化功能 (5项)

1. **✅ AI智能断言生成** - AI根据接口语义自动生成合理的业务断言规则
2. **✅ API文档Markdown导出** - 一键导出所有接口的Markdown格式文档
3. **✅ API变更检测** - 每次扫描自动检测新增/删除接口，树中用颜色标记
4. **✅ 请求/响应Diff对比** - 历史记录支持选择两条进行差异对比（新增绿色/删除红色高亮）
5. **✅ 接口使用频率统计** - 记录调用次数和最后调用时间，常用接口自动置顶

## 🚀 使用说明

### 快速开始
1. 右侧工具栏点击「AcaiApiHelper」打开面板
2. 点击「扫描API」自动识别项目中的Spring MVC接口
3. 左侧树选择接口，右侧填写参数后点击「发送」

### 环境管理
- 工具栏「管理」按钮打开环境配置对话框
- 支持配置多套环境（开发/测试/生产）的BaseURL和变量
- 在请求中使用 `{{variableName}}` 引用环境变量，例如 `Authorization: Bearer {{token}}`

### 断言配置
- 切换到「断言」Tab添加响应断言
- 支持状态码、响应时间、响应体内容、JSON字段值、响应头等多种断言类型
- 点击「🤖 AI生成断言」可让AI自动推断合理的断言规则

### 导出功能
- **导出cURL**：将当前请求复制为cURL命令，方便在终端/Postman中使用
- **导出文档**：导出所有接口为Markdown格式的API文档
- **导出报告**：测试完成后导出HTML测试报告

## 🔧 编译安装

```bash
./gradlew buildPlugin
```

编译产物位于 `build/distributions/` 目录，在IDEA中通过「设置 -> 插件 -> 从磁盘安装插件」选择zip包即可。

## 📁 数据存储位置

- 插件配置：`.idea/acai-api-helper.xml`（项目级）
- 测试报告：`.acai/reports/`
- 导出文档：`.acai/api-doc.md`

## 🎯 核心特性

### AI参数生成
对接火山引擎方舟(ARK)大模型，根据接口名、参数名、参数类型智能生成符合业务语义的测试数据。
支持正常值/边界值/异常值/全量覆盖四种场景。

### Git预提交检查
提交代码时自动测试受影响的Controller接口，测试失败可阻断提交，防止问题代码进入仓库。
- 每个接口按其预期状态码判定，不再一刀切使用200
- 失败时显示具体失败接口、状态码和错误信息

### 编辑器集成
- Controller方法行号旁显示API图标，点击快速打开调试面板
- 右键菜单支持「调试此接口」「收藏」「复制为cURL」等操作
- 双击API节点跳转到对应源码位置
